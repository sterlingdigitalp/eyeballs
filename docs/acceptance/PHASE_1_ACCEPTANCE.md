The current automated run contains 81 passing TypeScript tests across 20 suites plus the Rust
persistence test. It covers the integrated classifier/temporal/event pipeline, independent
calibration validation, target stability gates, ambiguity/out-of-distribution abstention, blink
suppression, review time alignment, correction precedence, labeled break/recovery timing, tracker
summaries, and interrupted session recovery.

## Calibration evidence to date

Brio run four collected 440 samples and passed the then-current
`cluster-hysteresis/1.1.0` gate at 94.0% overall. The local regression audit reprocessed that raw
calibration with the current `cluster-hysteresis/1.2.1`: overall agreement is 91.7%, but the physical-lens
target is 70%, below the new 80% lens-specific gate. The application therefore does not silently
activate run four under the new algorithm. A new run will use
`guided-personalized/2.0.1`, including five-second settle/collection holds and a separate
randomized validation pass.

## Required human/hardware evidence still open

- MacBook Practice: first independent calibration and repeated-session validation.
- Brio profile: rerun with the current algorithm and independent-validation protocol.
- Studio Capture: simultaneous Brio/Yeti paired-profile negotiation.
- USB disconnect, sleep/wake, Yeti mute/unmute/speaking-level gain using the new live dBFS meter, camera contention, and forced application termination.
- Same labeled corpus processed by Apple Vision and MediaPipe.
- Held-out user labels from both profiles at or above 85% contact/not-contact agreement.
- Fewer than one false corrective cue per minute during a known-contact drill.
- Blink, notes, side-screen, posture, low-light, and glasses cases.
- Stability across at least three sessions after calibration.

Phase 1 must not be marked accepted until these rows have recorded evidence. The application
deliberately reports `unknown` where the hardware/tracker evidence is insufficient.

The product owner accepted the 77.26-second, 2,319-frame Brio run as sufficient Phase 1
transport-stability evidence, so the originally proposed 30-minute Brio soak is not an open gate.
